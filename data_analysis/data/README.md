# Data

- `papers_dataset.csv`: the 1,018 scored impact records. Created by `metric_scoring/code/score_records.R`. Column descriptions are in `metric_scoring/README.md`.
- `papers_dataset_mechanisms.csv`: one row per record and mechanism, used in panel B of Figure_panel. Created by `code/prepare_mechanisms.R`.

Both files are generated by the code, so don't edit them by hand.
